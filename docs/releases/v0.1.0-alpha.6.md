# Lyvune v0.1.0-alpha.6

**Apple Music lyrics, with word-by-word karaoke, and no account or key.** It is still an alpha: back up your data before every update.

## What changed

- **Apple Music is a lyrics provider, on by default.** It sits next to LRCLIB and needs nothing from you: no account, no key. It reads the lrc.red catalogue (formerly `lyrics-api.binimum.org`), which serves Apple's lyrics as TTML with word or syllable timing for most songs. Checked live: *Blinding Lights* comes back with 275 word cues, taken as karaoke.
  - Word-timed results are tried first, at most three lyrics documents are fetched per search, and only `https` links are followed.
  - A song the catalogue does not have is an empty answer, and a rate limit is handled like any other provider's.
  - The "Apple Music: unavailable" placeholder is gone.
- **Nothing new is saved by itself.** Apple's lyrics are shown for the session; keeping them on disk needs a written authorization in the rights file, as for KuGou, NetEase and QQ Music.

Your lyrics files, locks, offsets, sidecars and the settings are unchanged. If you already saved your lyrics settings, add "Apple Music" to the providers there: saved settings win over the new default.

## What this does not do

- **Apple has no public lyrics API.** The catalogue is a third party, not Apple. It can change, start challenging clients, or disappear at any time, and then this provider stops finding lyrics until it is updated.
- Whether keeping Apple's lyrics is allowed is not known: neither Apple nor the catalogue publishes terms for this use.
- The catalogue's coverage varies from song to song; some results only have line timing.

## Updating, backup and going back

There are **no database changes** in this release.

```sh
docker compose exec lyvune lyvune backup create       # first, a backup
# in .env: LYVUNE_IMAGE=ghcr.io/tian-mc/lyvune:0.1.0-alpha.6
docker compose pull && docker compose up -d --no-build
docker compose ps                                      # wait for "healthy"
```

To go back, set `LYVUNE_IMAGE` to `ghcr.io/tian-mc/lyvune:0.1.0-alpha.5` and run the same two commands. Details: [Updating, and going back](../DOCKER.md#updating-and-going-back).
