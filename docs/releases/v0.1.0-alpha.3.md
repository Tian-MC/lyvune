# Lyvune v0.1.0-alpha.3

**KuGou lyrics no longer show HTML codes such as `eta&apos;`.** This is a small fix on top of alpha.2. It is still an alpha: back up your data before every update.

## What changed

- **KuGou word-timed lyrics (KRC) are decoded.** KuGou sends some characters as HTML character references: `eta&apos;` for `eta'`, `&quot;` for `"`, `&amp;` for `&`. Lyvune kept them as sent, so they showed up in the lyrics and in the karaoke words. They are now turned into the real characters when the lyrics are read, in the text, the translation and the romanization.
- **Karaoke stays in sync.** The word cues are built from the decoded words, so every word still points at the right place in the line. Times, order and background vocals are not changed.
- **Lyrics you already saved are fixed without touching your files.** A `.lyrics.json` saved by an earlier version from KuGou is decoded when it is read, and its word positions are moved with the text. The file is not rewritten and you do not need to download the lyrics again. New files carry a `textDecoded` mark, so nothing is decoded twice.
- **Same result everywhere.** The OpenSubsonic `getLyricsBySongId` (with or without `enhanced=true`), the legacy `getLyrics`, Jellyfin, the lyrics manager and the web player all show the corrected text. The translation settings from alpha.2 still apply.
- **Careful decoding.** Only complete references are decoded, once. `R&B`, `AT&T`, a lone `&`, unknown names and references that would become control characters are left alone, and `&amp;apos;` becomes `&apos;`, not `'`. The web player shows lyrics as text, never as HTML.

## Things to know

- Only KuGou needed this. LRCLIB, NetEase, QQ Music and lyrics from your own files, tags and imports are not changed.
- If KuGou had escaped a text twice and it came from KuGou's plain LRC, the second layer is decoded when an old file is read.
- Repeated stanzas, spelling and wording are the provider's content and are not touched.

## Updating, backup and going back

There are **no database changes** in this release.

```sh
docker compose exec lyvune lyvune backup create       # first, a backup
# in .env: LYVUNE_IMAGE=ghcr.io/tian-mc/lyvune:0.1.0-alpha.3
docker compose pull && docker compose up -d --no-build
docker compose ps                                      # wait for "healthy"
```

To go back, set `LYVUNE_IMAGE` to `ghcr.io/tian-mc/lyvune:0.1.0-alpha.2` and run the same two commands. The `textDecoded` mark is ignored by the older version, which shows the text as saved. Details: [Updating, and going back](../DOCKER.md#updating-and-going-back).
