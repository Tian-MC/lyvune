# Screenshots

These images show Lyvune with its **demo library**: music, covers and lyrics that were created for the project and
released under CC0 1.0. See [`scripts/demo-library`](../../scripts/demo-library/README.md) for what it is, how to make it
again and its licence. They were taken in an isolated Lyvune with its own empty database; no personal library or data
appears in them.

| File | Shows | Size |
| --- | --- | --- |
| `lyrics.webp` | the karaoke view: synchronized lyrics, the current words lit, the source of the lyrics | 1600 x 900 |
| `home.webp` | the home page | 1600 x 900 |
| `albums.webp` | the albums | 1600 x 900 |
| `album.webp` | an album, with the player bar | 1600 x 900 |
| `lyrics-romanization.webp` | Japanese lyrics with romanization, doubled vowels (`ou · aa`) | 1600 x 900 |
| `lyrics-romanization-macrons.webp` | the same with macrons (`ō · ā`) | 1600 x 900 |
| `lyrics-mobile.webp` | the lyrics view on a phone | 390 x 844 |
