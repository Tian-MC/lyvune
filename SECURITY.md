# Security policy

## Reporting a vulnerability

Please report security problems in Lyvune **privately**, not in a public issue or discussion.

Use GitHub's private vulnerability reporting: open the
[Report a vulnerability](https://github.com/Tian-MC/lyvune/security/advisories/new) form of this repository, and say what you
found and how to reproduce it. Only the maintainers can read what you send.

This channel is for **security problems in the software**: a way to read files or run code you should not, to bypass
authentication, to take over an account, and the like. It is not for questions, for ordinary bugs (open an
[issue](https://github.com/Tian-MC/lyvune/issues/new/choose)) or for reports about someone's behavior (see the
[Code of Conduct](CODE_OF_CONDUCT.md)).

## What to expect

Lyvune is an alpha, and it is looked after by one person. Reports are read as soon as the maintainer can, and there is no
guaranteed response time. Please give a reasonable time for a fix before you make a problem public.

## Supported versions

Only the latest release gets fixes. Today that is `0.1.0-alpha.4`; there is no long-term support.

## Navidrome

Lyvune is built on [Navidrome](https://github.com/navidrome/navidrome), and the server, the APIs and library scanning come
from it. If the problem is in code that comes from Navidrome and affects Navidrome too, it may also need to be reported to
that project. If you are not sure, report it here.
